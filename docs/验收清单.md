# edu-ops-dashboard 验收清单

本清单区分“代码已完成”“已在真实页面验证”和“已上线运行”，避免把模板或单元测试误当成生产部署。

| 阶段 | 当前结论 | 证据 | 尚缺条件 |
|---|---|---|---|
| P0 工程骨架 | 已完成 | `pyproject.toml`、`src/`、测试、ruff、CI、Git 版本记录 | 无 |
| P1 UI 兜底 | 已完成首版 | Chrome 已验证人工月、展开筛选、清除默认结业条件、查询、导出；文件校验器现已强制检查关键列、有效日期和日期范围，并写入 JSONL 运行记录 | 页面改版时需更新选择器 |
| P2 API PoC | 已完成只读验证 | 课消接口查询返回 JSON、导出通过 `download=1` 返回 XLSX；排课 `Course/QueryNew` 返回 `IsSuccess + Data{TotalCount, PageSize, PageIndex, List}` | 过期登录、权限不足、空结果的错误形态仍需补测 |
| P3 标准数据层 | 已完成首版 | `ScheduleRecord` 同时兼容 QueryNew 字段与 Excel 字段；日期、分钟转小时、实到/应到解析有测试 | 多学员明细是否拆成独立记录，待业务需要时确认 |

| P7 定时运行 | 模板与回退完成 | API→UI 回退、失败 JSONL、可选 macOS 通知、launchd plist | 需要替换路径、提供登录态，并由操作员加载 launchd |
