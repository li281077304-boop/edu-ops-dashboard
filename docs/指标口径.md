# 第一版指标口径

本文件是占位的业务规则边界，正式接入前需要用现有人工表逐项核对。

- 周平均课次：`本周周一起至昨日的累计排课节数 ÷ 固定教师人数`；不使用当日实际排课人数，也不做上周递推。
- 平均课时：`总课时 ÷ 总单科数`。它与周平均课次是两个并列指标，分母不能使用教师数。
- 人工月平均课时：人工月累计课时 ÷ 配置中的人工月实际周数；不按自然月天数推算。
- 预排/计划：一对一（含单学员 1v1）每节按 3 课时；其余一对多、集体班、基地班、1 对 2 等均按班课，每个应到学员按 1 课时。预排值单独保存，不覆盖实际值。
- 生产：已上课按实到、未上课按应到；一对一人数为 0 时计 0，班课按对应人数计。
- 预排快照：至少包含 `snapshot_date`、`target_week`、`metric`、`value` 和维度字段。
- 课时：使用导出数据的实际总小时数，不默认用排课节数乘 2 小时。

## 知识库对齐说明

- 工作知识库的周报结构将“平均课时 / 平均课次 / 教师数”列为并列字段；本项目分别存储，不共用分母。
- “平均课时”的分母 `总单科数` 必须由周报或课消数据提供，不能用教师数或排课行数替代。
- 工作知识库同时明确“排课不等于生产课时”：赠送课、亲属赠送、排课专用课程等是否计入生产，需要在原始数据存在可靠标记后配置；没有可靠标记时只输出排课/计划指标，不冒充绩效生产。

任何口径变更都应先改本文档和测试，再改 Dashboard。
