# Dashboard V0.1 产品化说明

## 运行 Python Dashboard

使用已下载的 Excel 生成正式 contract，并同时提供网页、API 和离线 JSON：

```bash
./start-dashboard.sh \
  --input "/path/to/排课列表.xlsx" \
  --one-to-one-students 100 \
  --total-students 200 \
  --big-week-ks 1300 \
  --small-week-ks 700 \
  --export-json ./widget-data.json
```

如果在读人数或大小周来源没有可靠数据，对应卡片会显示 `—`，不会使用旧 Demo 数字。`/widget-data.json` 和 `/api/status` 返回同一份数据；Android endpoint 默认指向 `/widget-data.json`。

只导出不启动网页服务：

```bash
./start-dashboard.sh --input "/path/to/排课列表.xlsx" --export-json ./widget-data.json --export-only
```

## Android App

工程目录：`android-widget/`。版本为 `0.1.0`，应用名为“经营看板”，Dashboard 名称从 payload 读取，同一个 APK 可以切换校区。

- 首次安装显示带“示例数据”标识的内置 v1 payload。
- “同步最新数据”只在 App 中联网；成功后校验并同步刷新 Widget，失败保留旧缓存。
- “导入数据文件”使用 Android 文件选择器读取 `widget-data.json`，校验失败不覆盖旧数据。
- “高级设置”才显示 endpoint 和 Dashboard ID；Widget 点击标题打开 App。
- Widget 绘制不联网，顺序为最近成功缓存 → 内置 sample；断网、电脑关机或服务停止时仍可查看最后数据。

## 构建

```bash
cd android-widget
ANDROID_SDK_ROOT=/tmp/android-sdk-widget-p0 ./gradlew clean testDebugUnitTest :app:assembleDebug
```

Debug APK 输出在 `android-widget/app/build/outputs/apk/debug/app-debug.apk`。构建产物、`local.properties`、本地缓存和认证文件均被忽略，不应提交。

## UAT 矩阵

| 验收 | 实施/自动证据 |
|---|---|
| Excel → Python → contract → JSON | `tests/test_dashboard_contract.py`、`--export-json` |
| API → Android parser → cache | `DashboardClient`、`WidgetPayload.fromDashboardJson` |
| 断网仍显示 | Widget 只读取 `SharedPreferences` 缓存 |
| 文件导入 | SAF `ACTION_OPEN_DOCUMENT` + schema 校验 |
| 错误 schema 不丢数据 | Python/Android invalid schema tests，写入前校验 |
| App kill/reboot persistence | payload 存储在 `SharedPreferences`；真机重启需人工确认 |
| 真机安装/桌面视觉 | 需要连接用户实体 Android 手机；不能用模拟器结果替代 |

当前未连接实体 Android 设备时，真机安装、桌面截图和断电重启只能标记为待做，不能宣称通过。
