# 校管家：人工月排课表下载流程

## 默认任务

当用户说“下本月排课表”或类似表达时，按人工月处理，不按自然月处理。

## 日期来源

读取同目录下的 `2026年人工月.csv`，根据当前日期落在哪一行确定人工月的开始日期和结束日期。

## Chrome 操作

1. 使用当前登录状态打开校管家，进入“教务管理 → 排课管理 → 排课列表”。
2. 确认当前校区；当前默认校区为“宣城二校”，如页面已切换则以页面实际选择为准。
3. 设置“上课时间”的开始日期和结束日期；人工月9为 `2026-08-31` 至 `2026-09-27`。
4. 点击“展开”，进入高级筛选。
5. 在“班级条件 → 结业状态”右侧，将鼠标移到字段末端使清除叉出现，点击叉清除“未结业”，确认字段显示“ 不限 ”。
6. 点击“查询”，确认结果数量和日期范围已经刷新。
7. 点击列表工具栏的“…”菜单，选择“导出排课”。
8. 确认 Chrome 显示“有新下载好的内容”。

## 约束

- 只查询和下载，不修改、删除或取消任何排课数据。
- 不把“未结业”误当成“未结课”；需要清除的是结业状态筛选。
- “排课节数”与“总小时数”按实际每节课时长统计，不默认用节数乘2小时。

代码入口：`edu_ops.collectors.xiaogj.ui_fallback.download_schedule_export`。页面选择器集中在该适配器中，后续页面改版只调整这里。
